# 7 Days to Die Map Renderer

Map renderer for 7 Days to Die.

- https://goemoncode.github.io/7dtd-map/

## Development (Deno)

This project runs on [Deno](https://deno.com/) (Deno 2.x+).

```bash
# 依存関係のインストール / キャッシュ
deno install

# 開発サーバーの起動
deno task dev

# プロダクションビルド
deno task build

# プレビューサーバーの起動
deno task preview

# 型チェック
deno task check

# コードの静的解析 (Linter)
deno task lint

# フォーマット
deno task fmt
```
